================================================================
         GUIDE DE LANCEMENT — OrientApp
================================================================

PRÉREQUIS
---------
Installer ces outils avant tout :
- PHP 8.2+       : https://www.php.net/downloads
- Composer       : https://getcomposer.org/download/
- Node.js 18+    : https://nodejs.org
- MySQL / XAMPP  : https://www.apachefriends.org/
- Git            : https://git-scm.com/downloads


----------------------------------------------------------------
1. CLONER LE PROJET
----------------------------------------------------------------

  git clone https://github.com/hamadou-abdoulaye/OrientApp.git
  cd OrientApp


----------------------------------------------------------------
2. CONFIGURER LA BASE DE DONNÉES
----------------------------------------------------------------

  OPTION A — Importer la BD directement (RECOMMANDÉ)
  ----------------------------------------------------
  Un fichier orientapp_db.sql est fourni dans le projet.

  1. Ouvrir XAMPP → démarrer Apache et MySQL
  2. Aller sur http://localhost/phpmyadmin
  3. Créer une base de données nommée : orientapp_db
  4. Cliquer sur Importer → choisir le fichier orientapp_db.sql
  5. Cliquer sur Exécuter

  Ou en ligne de commande :
  mysql -u root -p orientapp_db < orientapp_db.sql

  ✅ Toutes les tables et données sont importées automatiquement.
     Pas besoin de lancer php artisan migrate ni db:seed !


  OPTION B — Créer la BD manuellement (si OPTION A échoue)
  ----------------------------------------------------------
  1. Ouvrir XAMPP → démarrer Apache et MySQL
  2. Aller sur http://localhost/phpmyadmin
  3. Créer une base de données nommée : orientapp_db

  Ou en ligne de commande :
  mysql -u root -p
  CREATE DATABASE orientapp_db;
  exit;

  Puis lancer les migrations (voir étape 3).


----------------------------------------------------------------
3. LANCER LE BACKEND
----------------------------------------------------------------

  cd orientapp-backend

  # Installer les dépendances
  composer install

  # Copier le fichier de config
  cp .env.example .env

  # Générer la clé de l'application
  php artisan key:generate

  # Générer le secret JWT
  php artisan jwt:secret


  Ouvrir le fichier .env et modifier ces lignes :
  ------------------------------------------------
  APP_URL=http://127.0.0.1:8000

  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=orientapp_db
  DB_USERNAME=root
  DB_PASSWORD=          (vide si XAMPP par défaut)

  FILESYSTEM_DISK=public
  SESSION_DRIVER=cookie
  CACHE_STORE=file
  QUEUE_CONNECTION=sync


  Ensuite lancer ces commandes :
  -------------------------------
  # Créer les tables (seulement si OPTION B choisie à l'étape 2)
  php artisan migrate

  # Insérer les données (seulement si OPTION B choisie à l'étape 2)
  php artisan db:seed
  php artisan db:seed --class=UniversiteInfoSeeder

  # Créer le lien storage
  php artisan storage:link

  # Lancer le serveur
  php artisan serve

  ✅ Backend disponible sur : http://127.0.0.1:8000


----------------------------------------------------------------
4. LANCER LE FRONTEND
----------------------------------------------------------------

  Ouvrir un NOUVEAU terminal :

  cd orientapp-frontend

  # Installer les dépendances
  npm install

  # Lancer le serveur
  npm run dev

  ✅ Frontend disponible sur : http://localhost:5173

----------------------------------------------------------------
7. PROBLÈMES FRÉQUENTS
----------------------------------------------------------------

  ❌ Erreur "jwt:secret introuvable"
     → composer require tymon/jwt-auth

  ❌ Erreur de connexion à la base de données
     → Vérifier que MySQL est bien démarré
     → Vérifier DB_USERNAME et DB_PASSWORD dans .env

  ❌ Page blanche sur le frontend
     → Vérifier que le backend tourne sur http://127.0.0.1:8000
     → Ouvrir la console du navigateur (F12) pour voir l'erreur
